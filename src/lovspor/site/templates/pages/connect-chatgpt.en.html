What this is

lovverk is an MCP server that lets ChatGPT look up Norwegian acts and regulations. The hosted service lives at https://lovspor.no/mcp. You create a connector to it and sign in with OAuth 2.1 — there is no key to paste, and it costs nothing.

Connect in ChatGPT

These are the steps we have run in ChatGPT:

  1. Turn on developer mode in ChatGPT.
  2. Create a connector with the address https://lovspor.no/mcp.
  3. Choose OAuth as the authentication.
  4. Sign in on the page that opens. Once you are back in the chat, the tools answer.

Signing in

Once you have chosen OAuth, a sign-in page from WorkOS opens — the service we use for sign-in. You sign in there with an account; you can also sign in with another account, such as Google. lovspor receives only a user identifier from WorkOS, not your name or email address — see privacy. Afterwards you are sent back to ChatGPT.

Try a first question

Ask this in a new chat (it is Norwegian for “How long must I have worked to get sick pay from my employer?”):

«Hvor lenge må jeg ha jobbet for å få sykepenger fra arbeidsgiveren?»

The answer should rest on folketrygdloven § 8-18 and quote it: at least four weeks with the employer (the qualifying period). Then ask about folketrygdloven § 8-99 — the tool should answer that the section does not exist.

If it does not work

  • You cannot find where to create a connector. Turn on developer mode first; it was the first step when we ran the setup.
  • The sign-in does not start. Check that you chose OAuth as the authentication.
  • Authorization failed after you have signed in. Then the fault is in the setup on our side, not yours. Write to kontakt@lovspor.no.
  • A label has moved. The labels inside the client change more often than this page does. What matters is the address and OAuth as the way to sign in.
  • The tools do not answer. The state at the last release is on status. The service always requires sign-in, so a call without it is refused.

Without an account

ChatGPT connects to the hosted service. If you would rather run the server on your own machine, with no account, the procedure is in the Claude guide; for ChatGPT we have no tested local recipe.

Other clients: Connect. What the tools answer: the documentation. Questions: kontakt@lovspor.no.
