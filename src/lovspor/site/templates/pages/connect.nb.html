lovverk er en MCP-server. Klienten din snakker enten med den driftede tjenesten på https://lovspor.no/mcp, eller med en kopi du kjører på din egen maskin. Den første krever et token. Den andre krever ingenting.

Uten token

Du trenger ikke spørre noen om lov. Kjør serveren selv — den henter korpuset ned til maskinen din og snakker med klienten over stdio:

uvx lovspor fetch-corpus
claude mcp add lovverk -- uvx lovspor mcp

Dette virker i dag: ingen konto, intet token, ingen API-nøkkel. Alle verktøyene unntatt semantic_search leser bare filer og git på din egen maskin, og semantic_search trenger en embedding-nøkkel du selv setter inn.

Claude Code — den driftede tjenesten

Dette er framgangsmåten vi selv kjører, på én linje:

claude mcp add --transport http lovverk \
  https://lovspor.no/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Bytt YOUR_TOKEN mot tokenet du har fått. /mcp i en ny økt viser at lovverk er registrert.

Claude Desktop — lokal kopi

Legg dette inn i oppsettsfila til Claude Desktop (claude_desktop_config.json — hvor den ligger avhenger av operativsystemet) og start klienten på nytt:

{
  "mcpServers": {
    "lovverk": {
      "command": "uvx",
      "args": ["lovspor", "mcp"]
    }
  }
}

Claude Desktop og claude.ai — som connector

Den driftede tjenesten kan logge deg inn med OAuth 2.1 i stedet for at du limer inn et token, når vertsinnloggingen er slått på. Den veien er kjørt ende til ende fra Claude Desktop-connectoren: innloggingen fullføres, og verktøyene svarer.

Klikkestien inne i klienten skriver vi ikke opp her. Den endrer seg oftere enn denne siden gjør, og en oppskrift vi ikke har etterprøvd er verre enn ingen oppskrift — den ser riktig ut. Bruk klientens egen flyt for å legge til en connector, med adressen over.

ChatGPT, Cursor og Codex

Ingen testet framgangsmåte. Begge formene tjenesten tilbyr finnes på klientsiden: Cursor og Codex tar imot et token i et felt, og ChatGPT kobler til connectorer som logger inn med OAuth 2.1. Men vi har ikke kjørt oppsettet i disse klientene selv, og da dikter vi ikke opp stegene.

Bruk klientens egen dokumentasjon, med adressen https://lovspor.no/mcp og tokenet ditt. Får du det til — eller får du det ikke til — så si fra, så kan det stå her som en testet oppskrift med navnet ditt på.
