lovverk er en MCP-server. Klienten din snakker enten med den driftede tjenesten på https://lovspor.no/mcp, gjennom en connector du logger inn i med OAuth 2.1, eller med en kopi du kjører på din egen maskin, som ikke krever noe.

Claude Desktop og claude.ai — som connector

Den driftede tjenesten logger deg inn med OAuth 2.1, så du trenger ikke lime inn noe. Dette er framgangsmåten vi har kjørt fra claude.ai:

  • Legg til en egendefinert connector med adressen https://lovspor.no/mcp.
  • Velg Sign in now.
  • Velg Register automatically for klientregistrering. Standardvalget, som bruker Claudes publiserte identitet, virker ikke mot denne tjenesten.
  • Logg inn på siden som åpnes. Verktøyene svarer når du er tilbake i samtalen.

Merkelappene inne i klienten endrer seg oftere enn denne siden gjør. Har en av dem flyttet seg, er det adressen, OAuth som innloggingsmåte og automatisk registrering som teller.

ChatGPT — som connector

Også med OAuth 2.1. Framgangsmåten vi har kjørt:

  • Slå på utviklermodus (developer mode) i ChatGPT.
  • Opprett en connector med adressen https://lovspor.no/mcp og OAuth som autentisering.
  • Logg inn på siden som åpnes.

Kjør det selv

Du trenger ikke spørre noen om lov. Kjør serveren selv — den henter korpuset ned til maskinen din og snakker med klienten over stdio. I Claude Code:

uvx lovspor fetch-corpus
claude mcp add lovverk -- uvx lovspor mcp

Dette virker i dag: ingen konto, ingen API-nøkkel. Alle verktøyene unntatt semantic_search leser bare filer og git på din egen maskin, og semantic_search trenger en embedding-nøkkel du selv setter inn.

Claude Desktop — lokal kopi

Legg dette inn i oppsettsfila til Claude Desktop (claude_desktop_config.json — hvor den ligger avhenger av operativsystemet) og start klienten på nytt:

{
  "mcpServers": {
    "lovverk": {
      "command": "uvx",
      "args": ["lovspor", "mcp"]
    }
  }
}

Cursor og Codex

Ingen testet framgangsmåte. Vi har ikke kjørt oppsettet i disse klientene selv, og da dikter vi ikke opp stegene.

Bruk en klient som støtter en connector med innlogging via OAuth, eller kjør serveren selv som over. Får du en av disse klientene til å virke mot den driftede tjenesten — eller får du det ikke til — så si fra på kontakt@lovspor.no, så kan det stå her som en testet oppskrift med navnet ditt på.

Motoren er åpen kildekode under AGPL-3.0: github.com/bartoszkobylinski/lovspor. Hva verktøyene svarer på, står i dokumentasjonen; tilstanden ved siste utgivelse står på status.
