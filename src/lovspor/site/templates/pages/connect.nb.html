lovverk er en MCP-server. Klienten din snakker enten med den driftede tjenesten på https://lovspor.no/mcp, eller med en kopi du kjører på din egen maskin. Den første krever et token eller en innlogging med OAuth 2.1. Den andre krever ingenting.

Uten token

Du trenger ikke spørre noen om lov. Kjør serveren selv — den henter korpuset ned til maskinen din og snakker med klienten over stdio:

uvx lovspor fetch-corpus
claude mcp add lovverk -- uvx lovspor mcp

Dette virker i dag: ingen konto, intet token, ingen API-nøkkel. Alle verktøyene unntatt semantic_search leser bare filer og git på din egen maskin, og semantic_search trenger en embedding-nøkkel du selv setter inn.

Claude Code — den driftede tjenesten

Dette er framgangsmåten vi selv kjører, på én linje:

claude mcp add --transport http lovverk \
  https://lovspor.no/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Bytt YOUR_TOKEN mot tokenet du har fått. /mcp i en ny økt viser at lovverk er registrert.

Claude Desktop — lokal kopi

Legg dette inn i oppsettsfila til Claude Desktop (claude_desktop_config.json — hvor den ligger avhenger av operativsystemet) og start klienten på nytt:

{
  "mcpServers": {
    "lovverk": {
      "command": "uvx",
      "args": ["lovspor", "mcp"]
    }
  }
}

Claude Desktop og claude.ai — som connector

Den driftede tjenesten logger deg inn med OAuth 2.1, så du trenger ikke lime inn noe token. Dette er framgangsmåten vi har kjørt fra claude.ai:

  • Legg til en egendefinert connector med adressen https://lovspor.no/mcp.
  • Velg Sign in now.
  • Velg Register automatically for klientregistrering. Standardvalget, som bruker Claudes publiserte identitet, virker ikke mot denne tjenesten.
  • Logg inn på siden som åpnes. Verktøyene svarer når du er tilbake i samtalen.

Merkelappene inne i klienten endrer seg oftere enn denne siden gjør. Har en av dem flyttet seg, er det adressen, OAuth som innloggingsmåte og automatisk registrering som teller.

ChatGPT — som connector

Også med OAuth 2.1 og uten token. Framgangsmåten vi har kjørt:

  • Slå på utviklermodus (developer mode) i ChatGPT.
  • Opprett en connector med adressen https://lovspor.no/mcp og OAuth som autentisering.
  • Logg inn på siden som åpnes.

Cursor og Codex

Ingen testet framgangsmåte. Begge tar imot et token i et felt, som er formen tjenesten tilbyr dem. Men vi har ikke kjørt oppsettet i disse klientene selv, og da dikter vi ikke opp stegene.

Bruk klientens egen dokumentasjon, med adressen https://lovspor.no/mcp og tokenet ditt. Får du det til — eller får du det ikke til — så si fra, så kan det stå her som en testet oppskrift med navnet ditt på.
