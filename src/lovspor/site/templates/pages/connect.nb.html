lovverk er en MCP-server som gir KI-verktøyet ditt oppslag i norske lover og forskrifter. Den driftede tjenesten har én adresse:

https://lovspor.no/mcp

Ett klikk merker hele adressen eller kommandoen; kopier den med Ctrl+C (⌘C på Mac). Du logger inn i klienten, har ingenting å lime inn utover adressen, og det koster ingenting.

Claude

Kjørt fra claude.ai mot den driftede tjenesten {{ fact("code.connect.claude.walked_on", kind="code") }}.

  1. Legg til en egendefinert connector (custom connector).
  2. Oppgi adressen https://lovspor.no/mcp.
  3. Velg Sign in now.
  4. Under klientregistrering velger du Register automatically.
  5. Logg inn på siden som åpnes. Når du er tilbake i samtalen, svarer verktøyene.

Bruker du Claude Desktop, er det de samme valgene som teller, men stegene har vi bare kjørt fra claude.ai. Innloggingen og feilsøkingen står i hele veiledningen for Claude.

ChatGPT

Kjørt i ChatGPT mot den driftede tjenesten {{ fact("code.connect.chatgpt.walked_on", kind="code") }}.

  1. Slå på utviklermodus (developer mode) i ChatGPT.
  2. Opprett en connector med adressen https://lovspor.no/mcp.
  3. Velg OAuth som autentisering.
  4. Logg inn på siden som åpnes. Når du er tilbake i samtalen, svarer verktøyene.

Hvilke ChatGPT-abonnementer som har utviklermodus, har vi ikke kontrollert, så det står ikke her. Innloggingen og feilsøkingen står i hele veiledningen for ChatGPT.

Claude Code

Lokal kopi, uten konto

Serveren henter korpuset ned til maskinen din og snakker med Claude Code over stdio:

uvx lovspor fetch-corpus
claude mcp add lovverk -- uvx lovspor mcp

Alle verktøyene unntatt semantic_search leser da bare filer og git på din egen maskin. Claude Desktop som lokal kopi: se veiledningen for Claude.

Den driftede tjenesten

Kjørt i Claude Code mot den driftede tjenesten {{ fact("code.connect.claude-code.walked_on", kind="code") }}.

Legg til serveren:

claude mcp add --transport http lovverk https://lovspor.no/mcp
  1. Start Claude Code i samme prosjekt. Skriv /mcp i økten, velg lovverk og deretter Authenticate. Nettleseren åpnes.
  2. Logg inn med e-post eller Google.
  3. Velg Allow access. Siden advarer om at omdirigeringen peker til et ubekreftet program på maskinen din; det programmet er Claude Code.
  4. Siden sier Authentication successful. Tilbake i økten svarer verktøyene.

Åpnes ikke nettleseren, viser Claude Code lenken du kan kopiere. Viser siden etter Allow access en tilkoblingsfeil, limer du inn adressen fra nettleseren der Claude Code ber om den. Har du allerede den lokale kopien, gi denne et annet navn, for eksempel lovverk-hosted.

Andre klienter

Ingen testet framgangsmåte for Cursor, VS Code og Codex. Vi har ikke kjørt oppsettet i disse klientene selv, og da dikter vi ikke opp stegene eller oppsettsfilene.

Det en klient trenger for å bruke den driftede tjenesten:

  • adressen https://lovspor.no/mcp;
  • transporten Streamable HTTP;
  • innlogging med OAuth, som klienten starter selv.

Hvor dette legges inn, varierer fra klient til klient. Støtter ikke klienten innlogging, kan du kjøre serveren selv, som i den lokale kopien over.

Kom i gang

Tre spørsmål som prøver verktøyene. Still dem i en ny samtale.

«Hvor lenge må jeg ha jobbet for å få sykepenger fra arbeidsgiveren?»

Svaret skal bygge på folketrygdloven § 8-18 og sitere den. Spør deretter om folketrygdloven § 8-99 — verktøyet skal svare at bestemmelsen ikke finnes.

«Hvor høyt må taket være i et rom for varig opphold i en bolig?»

Svaret skal bygge på byggteknisk forskrift (TEK17) § 12-7, en forskrift og ikke en lov.

«Når ble arbeidsmiljøloven sist endret, og hva ble endret?»

Svaret skal bygge på endringshistorikken i korpuset, ikke på modellens hukommelse.

Hjelp

  • Modellen bruker ikke lovverk. Be om det med ord: «Slå opp i lovverk …». En modell velger selv når den kaller et verktøy.
  • Authorization failed etter at du har logget inn. Da ligger feilen i oppsettet på vår side, ikke hos deg. Skriv til kontakt@lovspor.no.
  • En merkelapp har flyttet seg. Merkelappene inne i klientene endrer seg oftere enn denne siden. Det som teller, er adressen og OAuth som innloggingsmåte.
  • Verktøyene svarer ikke. Tilstanden ved siste utgivelse står på status. Tjenesten krever alltid innlogging, så et kall uten den blir avvist.
  • Hva kan verktøyene svare på? Det står i dokumentasjonen.
