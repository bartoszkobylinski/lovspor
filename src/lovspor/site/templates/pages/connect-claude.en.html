What this is

lovverk is an MCP server that lets Claude look up Norwegian acts and regulations. The hosted service lives at https://lovspor.no/mcp. You add it as a custom connector and sign in with OAuth 2.1 — there is no key to paste, and it costs nothing.

Connect in claude.ai

These are the steps we have run from claude.ai:

  1. Add a custom connector.
  2. Enter the address https://lovspor.no/mcp.
  3. Choose Sign in now.
  4. For client registration, choose Register automatically.
  5. Sign in on the page that opens. Once you are back in the chat, the tools answer.

In Claude Desktop the same choices are what matter — the address, Sign in now and Register automatically — but we have run the steps from claude.ai only.

Signing in

When you choose Sign in now, a sign-in page from WorkOS opens — the service we use for sign-in. You sign in there with an account; you can also sign in with another account, such as Google. lovspor receives only a user identifier from WorkOS, not your name or email address — see privacy. Afterwards you are sent back to Claude.

Try a first question

Ask this in a new chat (it is Norwegian for “How long must I have worked to get sick pay from my employer?”):

«Hvor lenge må jeg ha jobbet for å få sykepenger fra arbeidsgiveren?»

The answer should rest on folketrygdloven § 8-18 and quote it: at least four weeks with the employer (the qualifying period). Then ask about folketrygdloven § 8-99 — the tool should answer that the section does not exist.

If it does not work

  • Registration fails. Check that you chose Register automatically. The default, Use Claude's published identity, does not work with this service.
  • Authorization failed after you have signed in. Then the fault is in the setup on our side, not yours. Write to kontakt@lovspor.no.
  • A label has moved. The labels inside the client change more often than this page does. What matters is the address, OAuth as the way to sign in, and automatic registration.
  • The tools do not answer. The state at the last release is on status. The service always requires sign-in, so a call without it is refused. If the hosted service is down, you can run the server yourself, as below.

Run it yourself

No account and no key: the server fetches the corpus down to your machine and talks to your client over stdio. In Claude Code:

uvx lovspor fetch-corpus
claude mcp add lovverk -- uvx lovspor mcp

In Claude Desktop, add this to the config file (claude_desktop_config.json — its location depends on your operating system) and restart the client:

{
  "mcpServers": {
    "lovverk": {
      "command": "uvx",
      "args": ["lovspor", "mcp"]
    }
  }
}

Every tool except semantic_search then reads only files and git on your own machine; semantic_search needs an embedding key you supply yourself. Other clients: Connect. What the tools answer: the documentation. Questions: kontakt@lovspor.no.
