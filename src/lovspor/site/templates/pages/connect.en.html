lovverk is an MCP server. Your client talks either to the hosted service at https://lovspor.no/mcp, or to a copy you run on your own machine. The first needs a token. The second needs nothing.

Without a token

You do not have to ask anyone. Run the server yourself — it fetches the corpus down to your machine and talks to your client over stdio:

uvx lovspor fetch-corpus
claude mcp add lovverk -- uvx lovspor mcp

This works today: no account, no token, no API key. Every tool except semantic_search reads only files and git on your own machine, and semantic_search needs an embedding key you supply yourself.

Claude Code — the hosted service

This is the procedure we run ourselves, in one line:

claude mcp add --transport http lovverk \
  https://lovspor.no/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Replace YOUR_TOKEN with the token you were given. /mcp in a fresh session shows that lovverk is registered.

Claude Desktop — a local copy

Add this to the Claude Desktop config file (claude_desktop_config.json — its location depends on your operating system) and restart the client:

{
  "mcpServers": {
    "lovverk": {
      "command": "uvx",
      "args": ["lovspor", "mcp"]
    }
  }
}

Claude Desktop and claude.ai — as a connector

The hosted service can log you in with OAuth 2.1 instead of you pasting a token, when hosted login is switched on. That path has been run end to end from the Claude Desktop connector: the login completes, and the tools answer.

We do not write down the click path inside the client. It changes more often than this page does, and a recipe we have not checked is worse than no recipe — it looks right. Use the client's own add-a-connector flow, with the address above.

ChatGPT, Cursor and Codex

No tested procedure. Both of the forms the service offers exist on the client side: Cursor and Codex accept a token in a field, and ChatGPT connects to connectors that log in with OAuth 2.1. But we have not run the setup in these clients ourselves, and we are not going to invent the steps.

Use the client's own documentation, with the address https://lovspor.no/mcp and your token. If you get it working — or if you cannot — tell us, and it can stand here as a tested recipe with your name on it.
